## 目标
- 网络安全与数字取证  
- 开源与 LINUX 工程  
- 云计算、DEVOPS 与基础设施安全  
- 跨境研究与教育（中国/印度尼西亚）  

## 宗旨
1. 加强中国与印度尼西亚在网络防御领域的国际合作。  
2. 推动技术与网络安全领域的伦理标准与意识提升。  
3. 培养具备 LINUX、开源技术与网络防御能力的高素质人才。  
4. 为社会与产业创新安全、负责任的数字化解决方案。  
5. 建立学术界、实践者与开源社区之间的紧密联系。
